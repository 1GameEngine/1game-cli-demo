# 触屏 2048

基于 [@1game/skill](https://www.npmjs.com/package/@1game/skill) 工作流开发的触屏 2048 小游戏，使用 `@1game/engine-bundle` 实现。

## 特性

- 4×4 经典 2048 玩法
- 触屏滑动操作（支持键盘方向键）
- 方块滑动与合并动画（easeOutCubic 缓动）
- 分数与最高分记录
- 达成 2048 提示 / 无路可走时游戏结束

## 开发与构建

```bash
npm install
npm run build
```

构建产物位于 `out/index.html`，用浏览器打开即可游玩。

## 操作说明

- **开始**：点击屏幕或向任意方向滑动
- **移动**：上下左右滑动合并相同数字
- **继续**：达成 2048 后点击继续挑战更高分
- **重开**：游戏结束后点击重新开始
