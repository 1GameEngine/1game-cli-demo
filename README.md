# 1game-cli-demo

1Game 示例仓库，包含触屏扫雷小游戏。

## 项目

| 目录 | 说明 |
|------|------|
| [minesweeper](./minesweeper) | 9×12 触屏扫雷（`pnpm build` → `out/index.html`） |

## 快速开始

```bash
cd minesweeper
pnpm install
pnpm build
# 浏览器打开 minesweeper/out/index.html
```

开发规范参考 npm 包 `@1game/skill`（`1game-game-dev` Agent Skill）。
