# 1game-cli-demo

A simple Snake game built with the 1Game public packages, following the workflow from `@1game/skill`.

## Tech stack

- `@1game/skill` as the development skill package reference
- `@1game/engine-bundle` for runtime APIs
- `@1game/cli` for building browser output

## Install

```bash
npm install
```

## Build

```bash
npm run build
```

Build output is generated under `out/`.

## Controls

- Keyboard: Arrow keys / WASD
- Restart after game over: Space
- On-screen buttons are available at the bottom for pointer input
